# Community conduct

Be respectful, specific, and constructive. Welcome people with different
backgrounds and experience. Critique ideas and code rather than people.

Harassment, threats, discrimination, impersonation, doxxing, and sharing private
community content or credentials are not welcome. Respect requests to stop an
interaction and the boundaries of communities using this software.

Maintainers may remove content, limit participation, or close contributions that
violate these expectations. To report a concern privately, use the private channel
described in [SECURITY.md](SECURITY.md); public reports should contain no identifying
or sensitive details. Maintainers should handle reports discreetly and explain
actions to the people affected where appropriate.
